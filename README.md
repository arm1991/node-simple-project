## Simple Node.js Project
Simple node.js project with implementation of few REST API's

## Testing
To test this project you need to start live server via `Live Server` VsCode extension.

You can also run it in other domains just update .env file to support URL.

## Run Server
To run server you need to run scripts in correct order.
`npm i`

`npm run dev`

This will run dev server and you will be able to test API's
